# GTL-Enhancedcore

GregTech Leisure Enhanced（GregTech Leisure 增强版）整合包专属核心模组。

围绕工业生产、自动化与后期巨构，扩展机器、仓室、工具与兼容功能。**需配合指定整合包及其依赖使用**，单独安装无法运行。

- 模组 ID：`gtl_enhancedcore`
- 环境：Minecraft 1.20.1 / Forge 47.x / Java 21
- 当前版本：3.2.3
- 许可：[LGPL-3.0](LICENSE)
- 作者：S_Fast

---

## 功能

### 工业生产

- **大型熔炉**：LV 基础并行 64、线程 2，升压分级增长；支持并行仓与线程引擎。
- **工业泛用蒸汽机**：13 类配方游戏内切换，固定 64 并行、100 桶内部缓存，每次开工扣 1 桶；外壳定级电压 HV 封顶。
- **基础矿石处理厂**：MV 基础并行 64、每级 +100；基础线程 1、每级 +2。
- **四台通用工厂 Plus**：处理 / 组装 / 分离 / 混合，单配方并行与分级上限。
- **四台 IV 工厂**：等离子机床、强子催化精炼塔、量子场质谱解离阵列、超导融合组装器。
- **通用联合工厂**：24 类配方；中央 11×13 面板（除主机 142 格）。

### 隔离订单

安装超级样板总成后，四台 IV 工厂、通用联合工厂以及 16 台原生白名单控制器支持跨配方类型隔离订单：

- 普通材料仓与超级总成互斥，至少需要一种材料仓。
- 普通材料仓保留机器原有配方模式与线程；超级总成启用隔离模式。
- 订单按共享预算公平分配，进度、库存、能量与产物持久化。
- 取消按钮立即终止未完成批次，退回可识别的未用原料，保留已完成产物。
- 超级总成自动命名只填空名，不覆盖已有名称。

### 后期巨构

恒星约束聚变堆、超构化学扭曲仪、铂系精炼矩阵、龙式场约束增殖核心、虚空约束采矿场、中子控制工厂、无限奇点压缩器。

> 恒星约束聚变堆 EU 从无线电网直接扣除，并行与跨配方线程为无限（实际上限受原料/输出/供电限制），单批固定 20 tick；结构只接受输入/输出仓。

### 无线能源

- **末晶谐振器 ×14**：LV–MAX，正上方放置末影水晶即可无线发电，**不消耗水晶**；LV 16A，其余 64A。
- **无线充能器 LV / MV**：11×11 区块，20 tick 周期，覆盖费按实际充入电量计算。

### 仓室与自动化

- **ME 元件集成仓**：10 页 × 63 格，支持元件挂载、自动补货与优先级。
- **量子数据访问仓**：10 页 × 81 格，读取闪存 / 数据球 / 数据模块。
- **电路编码仓**：虚拟供给 0–32 号电路，多选 / 全选 / 清空，不消耗电路。
- **创造算力数据靶仓**：为接受算力的多方块提供最高 2,100,000,000 CWU/t，仅创造模式获取。
- **样板生成工具**：机器 / 类型 / 电路 / 文字筛选，四组各 7 格标记（输入包含、输出包含、排除材料、排除产物），分页预览，本地预设，生成免费，支持直接填仓。

### 世界交互

- **气象锚点**：ZPM 4A，五种时间 / 天气模式。
- **因果重构终端**：六行映射，固定 0.1% 成功率，结果随进度保存，断电取消。
- **领地置换终端**：队伍强加载领地，旧 / 新方块幽灵槽，支持背包或 AE 供料。

### 整合适配

第三方巨构结构与配方调整、AE2 交互优化、JEI / Jade 信息与兼容修复。

## 构建

需要 **JDK 21**。

依赖 JAR 不随源码分发，需放入 `libs/` 目录，清单见 `gradle/local-dependencies.json`（构建时会校验，缺失会直接报错）。

```bash
# Windows
build.bat --no-pause --offline

# 或使用 Gradle Wrapper
gradlew.bat build
```

产物输出到 `build/libs/GTL-Enhancedcore-<版本>.jar`。

离线回归测试：

```bash
gradlew.bat regressionTest
```

源码结构：

| 目录 | 用途 |
|---|---|
| `src/main/java` | 模组主代码 |
| `src/main/resources` | 资源、语言文件、数据、Mixin 配置 |
| `src/test` | 离线回归测试 |
| `src/audit` | 隔离运行期审计（不进入正式产物） |
